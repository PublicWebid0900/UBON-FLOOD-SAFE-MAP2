# UBON FLOOD SAFE MAP
### แผนที่ดิจิทัลเพื่อการจัดการความเสี่ยงและความปลอดภัยของประชาชนในสถานการณ์น้ำท่วม ชุมชนบ้านหาดสวนยา จังหวัดอุบลราชธานี

นวัตกรรมโดยคณะนักศึกษา คณะรัฐศาสตร์ มหาวิทยาลัยอุบลราชธานี  
อาจารย์ที่ปรึกษา: ผู้ช่วยศาสตราจารย์ปฐวี โชติอนันต์  
รายวิชา: โครงสร้างเศรษฐกิจ สังคมและการเมืองของภาคอีสาน (ภาคเรียนที่ 1 ปีการศึกษา 2569)

---

## 🚀 ฟังก์ชันหลักของระบบ
- **แผนที่จุดเสี่ยงดิจิทัล (Interactive Risk Map)**: สัญลักษณ์ 8 สีมาตรฐาน (ผู้ป่วยติดเตียง, น้ำท่วมก่อน, ศาลปู่ตา, ศาลาชุมชน, ผู้สูงอายุ, ผู้พิการ, เด็กเล็ก, เสี่ยงไฟฟ้ารั่ว)
- **ระบบแจ้งจุดเสี่ยงโดยประชาชน ("พบจุดเสี่ยง? แจ้งเรา")**: รายงานเหตุการณ์พร้อมพิกัดและรูปถ่ายจากพื้นที่จริง
- **ระบบตรวจสอบข้อมูลโดยเจ้าหน้าที่ (Officer Verification Portal)**: คณะทำงานและหน่วยกู้ภัย/กฟภ. ตรวจสอบและอนุมัติขึ้นแผนที่สด
- **มาตรวัดระดับน้ำสถานี M.7 สะพานเสรีประชาธิปไตย**: แสดงระดับน้ำเทียบตลิ่ง 7.00 ม. พร้อมระบบจำลองสถานการณ์น้ำ
- **เครื่องมือวางแผนเส้นทางปลอดภัย (Safe Route Advisory)**: หลีกเลี่ยงถนนที่น้ำท่วมสูงและพื้นที่เสี่ยงไฟฟ้ารั่ว
- **คลังข้อมูลและบทเรียนมหาอุทกภัยปี 2562**: ถอดบทเรียนจากเหตุการณ์พายุโพดุลและคาจิกิ

## 🛠️ การติดตั้งและรันในเครื่อง (Local Development)

```bash
# ติดตั้ง dependencies
npm install --legacy-peer-deps

# รันโหมด Development
npm run dev

# Build สำหรับ Production
npm run build
```

## 🌐 การนำขึ้น GitHub Pages (GitHub Actions)

1. ทำการ Push โค้ดทั้งหมดขึ้น GitHub:
   ```bash
   git add .
   git commit -m "Update UBON FLOOD SAFE MAP and GitHub Pages config"
   git push origin main
   ```
2. เข้าไปที่ Repository บน GitHub ➔ แท็บ **Settings**
3. ที่เมนูด้านซ้าย เลือก **Pages**
4. ในหัวข้อ **Build and deployment** ช่อง **Source** ให้เลือกเป็น:
   **GitHub Actions**
5. ระบบจะทำการ Deploy ให้อัตโนมัติ สามารถเข้าชมเว็บไซต์ผ่านลิงก์ที่ GitHub ให้ได้ทันที
